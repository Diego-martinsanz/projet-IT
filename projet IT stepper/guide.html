Raccourcis
Les exemples sont visibles et copiable — collez-les dans l'Arduino IDE.
Astuce : copiez le code, ouvrez l'IDE Arduino, puis téléversez directement sur votre carte.

Avant de commencer

  • Matériel : Arduino (Uno/Nano), câble USB. Sur Windows vérifiez le driver si nécessaire.
  • Logiciels : Arduino IDE ou éditeur en ligne + navigateur moderne (Chrome/Edge recommandé).

1. Connexion

  1. Branchez l'Arduino via USB.
  2. Ouvrez le gestionnaire de port (Tools → Port) dans l'IDE.
Astuce : sur macOS/Linux les ports commencent par /dev/tty.* ou /dev/ttyUSB*.

2. Préparer et téléverser un programme

Exemple minimal : faire clignoter la LED intégrée (LED_BUILTIN). Le code est affiché en noir pour meilleure lisibilité.

// Exemple : clignotement simple
void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}
void loop() {
    digitalWrite(LED_BUILTIN, HIGH);
    delay(500);
    digitalWrite(LED_BUILTIN, LOW);
    delay(500);
}
  1. Collez ce code dans l'Arduino IDE, sélectionnez la carte et le port.
  2. Cliquez sur "Upload" pour téléverser. Ouvrez le Serial Monitor si besoin.

3. Utiliser le site

Le site propose un tableau de bord, un guide d'ateliers, et un tableau Stepper pour lire les impulsions via Web Serial.

Dépannage rapide

  • Upload échoue : vérifiez la carte et le port, changez de câble.
  • Site ne détecte pas l'Arduino : autorisez l'accès au port série et rafraîchissez la page.
